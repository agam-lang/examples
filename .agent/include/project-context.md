# Project Context

## What This Repository Is

- Repository: `agam-lang/examples`
- Purpose: Provide curated, well-documented example projects and tutorials that showcase Agam's capabilities across systems, AI, and scientific computing domains.
- Technology: Agam source files + documentation

## Organization Context

- This is part of the `agam-lang` ecosystem.
- The core Agam compiler lives at `agam-lang/agam`.
- The standard library lives at `agam-lang/std`.
- The scientific platform lives at `agam-lang/agamlab`.

## Key Areas

- Getting Started
- Systems Programming
- AI/ML
- Scientific Computing
- Web & Networking
